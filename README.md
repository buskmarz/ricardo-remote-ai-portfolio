# Ricardo Del Castillo Velasco - Career Portfolio

Static portfolio for remote U.S.-focused job search.

## Open Locally

From this folder:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://127.0.0.1:8765
```

## CV

The CV is generated from:

```text
tools/generate_cv.py
```

Run:

```bash
python3 tools/generate_cv.py
```

Outputs:

- `/Users/macbookair2020/Desktop/Ricardo_Del_Castillo_Remote_AI_Automation_CV.pdf`
- `output/Ricardo_Del_Castillo_Remote_AI_Automation_CV.pdf`

## Notes

- The portfolio is intentionally static so it can be published later on Netlify, Vercel, GitHub Pages or any simple static host.
- The copy focuses on business systems, AI automation, internal tools, full-stack products and operations technology.
